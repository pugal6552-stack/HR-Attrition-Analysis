# 📊 HR Attrition Analysis Dashboard | Power BI

## 📌 Project Overview
The HR Attrition Analysis Dashboard is a data analytics project developed using Microsoft Power BI. It helps explore employee attrition patterns and understand workforce trends through interactive visualizations and key performance indicators.

## 🎯 Project Objectives
- Analyze employee attrition patterns.
- Compare attrition across departments and employee groups.
- Explore workforce trends using interactive reports.
- Support data-driven HR decision-making.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for calculations and KPI measures
- Data Modeling
- Data Visualization

## 📈 Dashboard Highlights
- Employee and attrition KPI cards
- Department-wise attrition analysis
- Employee demographic analysis, where available
- Interactive charts and slicers
- Workforce trend analysis

## 💡 Business Value
The dashboard helps HR teams explore employee turnover, identify patterns in attrition, and make more informed workforce planning decisions.
